# 动植物物种生态关系系统 - 完整功能需求清单

## 项目概述
基于 MongoDB、Redis、Neo4j 三种 NoSQL 数据库开发的生态数据管理系统

---

## 必须使用的三种数据库及其用途

### 1. MongoDB（文档数据库）
- 用途：存储物种基础信息、栖息地信息、观测记录等结构化数据
- 负责：增删改查操作

### 2. Neo4j（图数据库）
- 用途：构建生态关系图谱，处理复杂关系网络
- 负责：关系查询、食物链分析、生态网络分析

### 3. Redis（键值数据库）
- 用途：缓存热门数据、会话管理、实时数据流处理
- 负责：提高访问速度、减少数据库压力

### 模块2: 生态关系管理模块
**数据库**: MongoDB + Neo4j（双数据库协同）

**必须实现的功能**:
1. 添加生态关系
   - MongoDB：插入关系记录（基础数据）
   - Neo4j：创建对应关系边（图结构）
   - 关系类型：捕食关系、竞争关系、共生关系、寄生关系

2. 删除生态关系
   - MongoDB：移除关系记录
   - Neo4j：删除对应关系边

3. 更新关系属性
   - MongoDB：更新关系文档
   - Neo4j：使用 SET 语句更新边属性

4. 查询生态关系
   - MongoDB：查询基础关系
   - Neo4j：复杂关系网络分析

**关系类型定义**:
- PREYS_ON: 捕食关系（A捕食B）
- COMPETES_WITH: 竞争关系
- SYMBIOSIS: 共生关系
- PARASITISM: 寄生关系

**Neo4j 图结构**:
- 节点：物种（Species）
- 边：生态关系（带类型和属性）

### 模块4: 缓存管理模块
**数据库**: Redis

**必须实现的功能**:
1. 增加缓存
   - 使用：SET 命令
   - 可设置过期时间（SETEX）

2. 删除缓存
   - 使用：DEL 命令

3. 更新缓存
   - 先 DEL 删除旧缓存，再 SET 添加新缓存

4. 查询缓存
   - 使用：GET 命令

**缓存策略**:
- 热门物种信息（访问频率高的）
- 生态关系查询结果
- 用户会话数据
- 缓存过期时间：1小时（3600秒）

**实现模式**:
```python
# 查询时先查缓存
cache_key = f'species:{species_id}'
cached = redis.get(cache_key)
if cached:
    return json.loads(cached)  # 缓存命中
else:
    # 缓存未命中，查MongoDB
    data = mongodb.find_one(...)
    redis.setex(cache_key, 3600, json.dumps(data))  # 更新缓存
    return data
```

### 模块5: 复杂关系查询模块
**数据库**: Neo4j

**必须实现的功能**:
1. 增加节点和边
   - 使用：Cypher 的 CREATE 语句

2. 删除节点和边
   - 使用：Cypher 的 DELETE 语句

3. 更新节点属性
   - 使用：Cypher 的 SET 语句

4. 复杂关系查询
   - 查询某物种的完整食物链
   - 分析生态网络中的关键路径
   - 使用：MATCH 和 RETURN 语句，支持深度查询和路径查询

**查询示例**:
```cypher
// 查询食物链（最短路径）
MATCH path = shortestPath(
  (start:Species {name: "东北虎"})-[:PREYS_ON*]->(end:Species {name: "草"})
)
RETURN [node in nodes(path) | node.name] as chain

// 查询某物种的所有猎物
MATCH (predator:Species {name: "东北虎"})-[:PREYS_ON]->(prey)
RETURN prey.name

// 查询某物种的天敌
MATCH (predator)-[:PREYS_ON]->(prey:Species {name: "梅花鹿"})
RETURN predator.name

// N跳关系查询（生态圈）
MATCH (s:Species {name: "东北虎"})-[:PREYS_ON*1..2]-(related)
RETURN DISTINCT related.name
```

## 数据库操作要求总结

### MongoDB 必须实现的操作
```python
# 插入
db.collection.insert_one(document)
db.collection.insert_many([doc1, doc2, ...])

# 查询
db.collection.find(query)
db.collection.find_one(query)

# 更新
db.collection.update_one(filter, {"$set": update_data})
db.collection.update_many(filter, {"$set": update_data})

# 删除
db.collection.delete_one(filter)
db.collection.delete_many(filter)

# 聚合查询（用于统计）
db.collection.aggregate([
    {"$group": {"_id": "$category", "count": {"$sum": 1}}}
])
```

### Neo4j 必须实现的操作
```cypher
// 创建节点
CREATE (s:Species {name: "东北虎", category: "哺乳动物"})

// 创建关系
MATCH (a:Species {name: "东北虎"})
MATCH (b:Species {name: "梅花鹿"})
CREATE (a)-[:PREYS_ON]->(b)

// 查询关系
MATCH (a)-[r:PREYS_ON]->(b)
RETURN a.name, b.name

// 查询路径
MATCH path = shortestPath((a)-[:PREYS_ON*]->(b))
RETURN path

// 删除
MATCH (s:Species {name: "xxx"})
DETACH DELETE s
```

### Redis 必须实现的操作
```python
# 字符串操作
redis.set('key', 'value')
redis.get('key')
redis.setex('key', 3600, 'value')  # 带过期时间

# 删除
redis.delete('key')

# 检查存在
redis.exists('key')

# 计数器（用于统计访问量）
redis.incr('visit:species:123')

# 有序集合（用于排行榜）
redis.zadd('popular_species', {'东北虎': 100})
redis.zrevrange('popular_species', 0, 9, withscores=True)
```
